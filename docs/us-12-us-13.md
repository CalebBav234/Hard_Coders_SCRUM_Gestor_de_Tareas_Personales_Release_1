# US-12 y US-13: historial y búsqueda de tareas

## Alcance implementado

- **US-12 — Historial unificado:** la interfaz muestra tareas terminadas y eliminadas lógicamente. Cada tarjeta conserva su título, descripción, prioridad, categoría, tiempo activo y una línea temporal desplegable con los cambios de estado.
- **US-13 — Buscar tareas:** las listas de tareas actuales y de historial tienen búsquedas independientes por título o descripción.

La búsqueda se ejecuta en PostgreSQL, es parcial e ignora mayúsculas y acentos. Los caracteres `%`, `_` y `\` se tratan como texto literal para evitar coincidencias inesperadas. La consulta admite hasta 160 caracteres y usa parámetros enlazados; no concatena entradas del usuario en SQL.

## API

```http
GET /api/tasks?q=informe
GET /api/tasks/history?q=reunion
```

`q` es opcional. Si falta o contiene solo espacios, se devuelve la lista completa correspondiente.

El historial devuelve cada tarea archivada con un arreglo `events`, ordenado del cambio más reciente al más antiguo:

```json
{
  "id": 12,
  "title": "Preparar reunión",
  "status": "TERMINADA",
  "deletedAt": null,
  "events": [
    {
      "fromStatus": "ACTIVA",
      "toStatus": "TERMINADA",
      "changedAt": "2026-08-31T18:00:00Z"
    }
  ]
}
```

## Base de datos

Antes de iniciar el backend, cada integrante debe actualizar `develop` y ejecutar desde la raíz:

```powershell
.\database\scripts\migrate.ps1
.\database\scripts\verify-local.ps1
```

La migración `V003__task_archive.sql` crea `task_manager.v_task_archive`. Esta vista incluye tareas con estado `TERMINADA` o con `deleted_at` informado. En una tarea activa eliminada, el tiempo efectivo queda congelado en la fecha de eliminación.

## Uso en la interfaz

1. En **Mis tareas**, escribe texto y pulsa **Buscar** para filtrar las tareas visibles.
2. En **Historial de tareas**, consulta las terminadas y eliminadas; usa su campo de búsqueda para recuperar contexto anterior.
3. Pulsa **Ver cambios de estado** para desplegar la línea temporal.
4. Pulsa **Limpiar** para volver a la lista completa.

Al completar, reabrir, editar o eliminar una tarea, la sección de historial se actualiza automáticamente. Los errores de red y las búsquedas sin coincidencias muestran mensajes controlados y comprensibles.
